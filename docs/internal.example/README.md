# Internal operator docs (local only)

Deploy, database, and security runbooks are **not** stored in this repository.

Keep them on your machine under `docs/internal/` (gitignored), for example:

- `DEPLOY-CHECKLIST.md` — production deploy and env checklist
- `HETZNER-MONGO-REPLICA.md` — database replica setup
- `compliance-audit.md` — compliance audit notes

Do not link these from public pages or commit them to git.
